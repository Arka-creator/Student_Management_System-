# Student Management System
A simple command-line **Student Management System** built with **Python** and **MySQL**. This project demonstrates how to connect Python with a MySQL database and perform basic CRUD (Create, Read, Search, Delete) operations.

## Features
-  Add a new student
- View all students
- Search students by name
- Delete students by ID
- Secure MySQL password input using `getpass`

## Technologies Used
- Python 3
- MySQL
- mysql-connector-python


## How to Run
1. Clone this repository.
```bash
git clone https://github.com/your-username/student-management-system.git
```
2. Navigate to the project folder.
```bash
cd student-management-system
```
3. Install the required package.
```bash
pip install mysql-connector-python
```
4. Run the program.
```bash
python student_management.py
```
5. Enter your MySQL password when prompted.
